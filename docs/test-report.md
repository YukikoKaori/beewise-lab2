## Review findings addressed

See [code-review.md](code-review.md) for the complete review log, including Lab 3 findings (`BW-01..BW-06`, `BW-C01..BW-C09`) and PRM393 Final static/runtime findings (`F-FINAL-01..F-FINAL-06`), summarized below:

1. Approval without a notice could strand the applicant. One Firestore transaction writes the status and immutable receipt; Rules validate both final documents together and refuse forged, standalone or concurrent competing decisions.
2. Cached staff data could outlast role removal. The Web waits for a server role snapshot and uses a role-owned navigator so dialogs disappear when access is revoked; `F-FINAL-01` is now fixed with `useRootNavigator: false` on both VietQR payment dialogs (`web/lib/payment_workspace.dart`), and Firestore remains authoritative for writes.
3. Sending raw free text could disclose contact information to the model. The app extracts allowlisted academic hints, rejects invalid structured output, and routes to editable manual filters if AI cannot run.
4. Real emulator validation found that a label dropped the title of a general announcement and that approved status copy implied a public listing. Final labels now include the title and distinguish tutor access from public publication.
5. Corrective audit: direct-write regressions reject acceptance without the exact amount, verification with the wrong transfer reference, and verification with a missing or mismatched recipient. The staff-issued first class offer supplies the price; parent confirmation explicitly binds that price before QR display. Actual posted credit remains a staff decision, never a Rules assertion.
6. Corrective audit: the Level 2 parser rejects even schema-valid output values absent from the projected educational hints. Regression tests cover all six fields.
7. PRM393 Final static & runtime review (`F-FINAL-01..F-FINAL-06` in [code-review.md](code-review.md)): `F-FINAL-06` (`e2e_test/test_final_flows.py:41`) was fixed in PR #30 (`2d14aa0`), and `F-FINAL-01..F-FINAL-05` are now fixed with regression tests on `fix/final-corrective-acceptance` (rebased onto `2d14aa0`): `useRootNavigator: false` + `expectedStatus` cancel on Web (`F-FINAL-01`), per-parse `ai_result_accepted` deduplication (`F-FINAL-02`), transactional `ManualPayments.cancel` (`F-FINAL-03`), unified 16-region canonical location contract + alias/hierarchy matching + updated `resubmissionServerBlockMessage` (`F-FINAL-04`), and fail-closed Analytics privacy state machine + manifest default `false` + UI error surfacing + identity cleanup on sign-out/account switch (`F-FINAL-05`).
