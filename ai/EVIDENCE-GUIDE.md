# Hướng dẫn minh chứng

1. Sao chép từng ảnh trước/sau vào `assets/ux-critique/UX-0X/` với tên `before.png`, `after.png`.
2. Dán nguyên văn prompt đã chạy vào `ai/prompts/UX-0X.txt`.
3. Trong `ai/ux-critique.md`, điền đánh giá After dựa trên hình thật.
4. Trong `ai/iterations/`, điền ngày giờ, thứ tự prompt, kết quả và quyết định Accept/Modify further/Reject.
5. Kiểm tra ảnh hiện trực tiếp trên GitHub và liên kết không lỗi.
6. Ghi lại URL Figma và link prototype trong README chính của repository.

**Lưu ý:** File markdown mẫu chưa phải bằng chứng đã chạy Stitch. Ảnh After cần là sản phẩm thật.
